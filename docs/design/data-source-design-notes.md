# 数据源管理与同步机制设计说明 v0.1

## 页面任务

本轮不增加独立的“数据源管理”页面。数据接入收敛到经营总览已有的数据导入区域，通过一个“数据接入”按钮打开弹窗，让用户确认四件事：数据从哪里来、更新到什么时候、数据是否可用、本次更新影响了哪些经营判断。

经营总览内包含：

1. 全局数据状态条：当前来源、最近成功同步、数据截止时间、下次同步和完整度；
2. 数据接入按钮：打开弹窗，不新增侧边导航；
3. 数据接入弹窗：默认示例、本地 CSV、公开在线 CSV 三种方式；
4. 弹窗质量预览：新增、覆盖、跳过行数及即将生效的数据范围；
5. 同步反馈：使用状态条和 Toast 告知成功、失败及受影响的异常和工单，不另做同步历史页面。

飞书和 Hive 不出现在本轮可操作界面中，只在 README 的后续连接器架构中说明。

## 模拟在线 CSV 怎么实现

静态 CSV 链接不会自己变化，因此 Demo 使用“可控版本的准实时数据源”：

```text
前端保存当前模拟版本 v1
→ 用户点击“立即同步”或到达模拟同步时间
→ 请求 /api/demo-live.csv?version=2
→ 服务端返回新的完整 30 天 CSV 快照
→ 前端沿用现有 CSV 校验器解析
→ 校验通过后替换当前生效快照
→ 重新计算看板、异常、工单监控和周度复盘
→ 当前版本推进到 v2
```

建议准备四个确定性版本：

| 版本 | 数据状态 | 用于演示 |
| --- | --- | --- |
| v1 | 经营基本正常 | 首次连接和建立基线 |
| v2 | 洁面 SKU 退款与履约同时恶化 | 新异常被发现并创建工单 |
| v3 | 执行动作后发货改善，退款仍高 | 工单显示“改善中” |
| v4 | 观察窗口完整且指标退出阈值 | 系统反馈“已恢复”，等待用户关单 |

MVP 每次返回完整 30 天快照，不做真正的流式增量。这样既能复用现有聚合和诊断引擎，也能保证面试演示结果可重复。页面必须明确标注“模拟在线数据源”，不能称为真实平台实时数据。

## 为什么要通过服务端读取链接

浏览器直接读取任意外部 CSV 经常会被 CORS 拦截，也无法安全保存未来连接器的凭据。因此正式链路应是：

```text
网页提交数据源配置
→ Vercel Function 在服务端抓取
→ 校验响应类型、大小、超时和目标地址
→ 返回标准化数据或质量报告
```

公开 Demo 只接受无鉴权 HTTPS 链接。服务端需要限制文件大小和响应时间，并阻止 localhost、内网 IP 和非 HTTP(S) 协议，避免把链接抓取接口变成任意网络代理。

## 数据更新规则

- 标准主键：`date + sku_id`；
- 在线 CSV 首版采用全量快照覆盖；
- 新版本只有在必填字段齐全且至少有一行有效数据时才发布；
- 非法行跳过并给出质量提示；
- 同步失败时保留上次成功版本，不能清空看板；
- 每个生效版本保存 `sourceId`、`versionId`、抓取时间、数据截止日期、行数和质量摘要；
- 工单继续使用创建时冻结的异常快照，以最新数据评估恢复状态。

## 同步频率

公开 Demo 中提供“手动同步”和“模拟每 30 分钟同步”。浏览器关闭后不会真正后台运行；页面再次打开时，根据 `nextSyncAt` 判断是否补做一次同步。

真实后台定时监控需要 Vercel Cron 或其他任务调度器，并需要数据库保存数据源、同步版本和运行状态，这不属于当前纯 localStorage MVP。

## Hive 边界

Hive 不是一个可以粘贴到浏览器直接读取的普通表格链接。真实接入需要企业内网、连接驱动、鉴权、SQL 模板和凭据托管。因此本轮只在信息架构中保留“企业连接器”入口，不展示虚假连接成功状态。

## 已确认的 MVP 边界

- 不新增数据源管理独立页面；
- 复用经营总览的数据上传入口；
- 真正实现默认示例、本地 CSV 和公开在线 CSV；
- 在线 CSV 支持连接测试、手动刷新和模拟 30 分钟同步；
- 使用 v1—v4 可控数据版本演示正常、异常、改善和恢复；
- 飞书和 Hive 留作后续连接器，不在页面中伪装已接通。

## 建议开发拆分

1. 数据源类型、同步记录和数据版本模型；
2. 模拟在线 CSV 的 v1—v4 数据与服务端接口；
3. 添加数据源抽屉和连接测试；
4. 字段映射与质量预览；
5. 手动同步、模拟自动同步和失败保底；
6. 同步后触发看板、诊断、工单与复盘重算；
7. 经营总览接入弹窗与状态提示；
8. 自动测试和演示脚本。

## 低保真交互确认稿

低保真图见 `data-source-wireframe.svg` / `data-source-wireframe.png`。交互分为五个状态：

1. 经营总览顶部点击“数据接入”；
2. 在弹窗选择默认示例、本地 CSV 或公开在线 CSV；
3. 填写在线链接并测试连接，设置手动或模拟 30 分钟同步；
4. 查看 14 个标准字段、有效行、跳过行和覆盖周期，确认“保存并同步”；
5. 成功时提示新版本和新增异常，失败时继续使用上次成功版本。

首版不提供复杂的字段映射编辑器。字段名称必须符合模板；缺少必填字段时明确列出并阻止生效。
